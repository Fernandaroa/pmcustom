# PMCustom

necesito crear dos propuestas de sitio web para este cliente https://www.pmcustom.cl/ por ahora el contenido se mantiene asi que copialo tal cual. El objetivo del sitio es mostrar los servicios pero con una finalidad de obtener clientes, por lo cual debe tener formulario de contacto, base de datos,. Tengo dos ideas de sitio web, por que queremos que el sitio sea didactivo, interactivo, moderno sin perder el objetivo del servicio y tecnologia. Los sitios de referencia que quiero que tomes y armes las nuevas dos propuestas, mezclando ambas ideas, pero generando dos propuestas distintas son:
https://zetta-joule.com/
https://renaudigital.com/en/
Preguntame todo lo que necesites antes de empezar.
